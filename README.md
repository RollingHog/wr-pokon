## Игра на двоих по локальной сети

Нужен Python 3.7+ (зависимостей нет, только стандартная библиотека).

1. На одном компьютере из корня проекта: `python serve.py`.
2. На обоих компьютерах открыть одну и ту же страницу кампании с `?net=1`,
   например `http://192.168.1.5:8123/custom/pokras-spc.html?net=1`
   (адрес покажет сам сервер при запуске).
3. «Передать ход» — отправить текущее состояние на сервер; «Загрузить ход» —
   взять ход соперника. Когда соперник передал ход, кнопка подсвечивается,
   а при открытии страницы актуальный ход подгружается автоматически.

Первый «Передать ход» создаёт общий сейв. Сейв хранится в `.net/save.json`
и в git не попадает. Если сервер не запущен или порт закрыт файрволом,
статус рядом с кнопками сообщит об ошибке.
