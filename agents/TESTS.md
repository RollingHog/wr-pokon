# Тестирование движка index.js

*План и статус. Составлено 2026-09-05. Связано с [REFACTORING.md](REFACTORING.md):
тесты — регрессионная защита при выделении модулей.*

## Что уже есть

- **`Tests.html`** (корень) — копия `ChillyMorning.html`, последним подключён
  `tests/tests.js`. Открывается как обычная страница; справа сверху появляется
  панель результатов (кнопка «↻ перезапустить» перегружает страницу).
- **`tests/tests.js`** — микро-раннер + 13 тестов, ноль внешних зависимостей.

Как это работает:

- Тесты вызывают глобальные функции движка напрямую (`placeShape`, `onEndTurn`,
  `selection.damage`, …) — возможно, потому что index.js не обёрнут в IIFE.
- Честная эмуляция мыши: `MouseEvent`/`WheelEvent` диспатчатся на `fogCanvas`
  (drag, выделение кликом, зум).
- Подменяются глобальные `confirm`/`alert`/`prompt` и `saveFile` — вместо
  диалогов и скачивания файл попадает в `savedFiles` и парсится тестом.
- `resetGame()` даёт каждому тесту чистое состояние (пустая карта или копия
  `DEFAULT_DATA`, нулевые ресурсы/техи/закладки, scale=1).

Запуск: просто открыть `Tests.html` по file:// — все тесты кроме экспорта PNG
работают локально. Для сценариев с `toDataURL`/`getImageData` (canvas taint на
file://) нужен любой статический сервер, например `python -m http.server`.

## Уже покрыто (13 тестов)

1. Список игроков: порядок, поиск по цвету/имени, NPC.
2. Выбор игрока: `getShapeColor`, `Players.current`, панель эффектов.
3. Размещение юнита мышью (превью + `placeShape`): поля объекта.
4. Оплата: без ресурсов блокируется, с ресурсами списывает цену фермы.
5. Выделение кликом + урон здания до смерти → `_обломки`.
6. Урон юнита до смерти → `_могила`.
7. Перетаскивание юнита мышью (координаты меняются, выделение остаётся).
8. Перетаскивание пустого места двигает карту (`canvasOffsetX/Y`).
9. Зум колесом: множитель, подпись, границы масштаба.
10. Конец хода: confirm при непоходивших, `CURRENT_TURN`, доход/обнуление
    отрицательного, сброс `endedTurn`, autosave.
11. `saveGame`: содержимое файла парсится, совпадает с состоянием.
12. Pins: закладка за владельцем и снятие, `toJSON`.
13. `sumPlayerEffects`: доход фермы + содержание юнита, счётчики,
    ресурсы с нулевым доходом присутствуют.

## Найденные при написании тестов баги базовой кампании

В `src/rules.js` в `DEFAULT` отсутствуют ключи, без которых движок падает:

- **`noUpkeep`** — TypeError при любом подсчёте эффектов игрока
  (`getRawEffectsList`), т.е. размещение объекта на ChillyMorning ломается.
- **`wreckUnit`** — TypeError при смерти юнита (`killObj`).

На кастомных кампаниях эти ключи заданы. Пока их не добавят в `src/rules.js`,
`tests/tests.js` дозаполняет их сам (с комментарием). Правильное решение —
добавить `noUpkeep: []` и `wreckUnit: []` в DEFAULT в `src/rules.js`.
