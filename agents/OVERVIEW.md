# Обзор проекта wr-pokon

*Датa обзора: 2026-09-05. Краткая выжимка «что это и как устроено».*

## Что это

Набор браузерных (без сборки, чистый vanilla JS) инструментов для настольной/
постовой стратегии с гексагональной картой: интерактивный редактор/менеджер
карты партии с туманом войны, юнитами, зданиями, ходами и т.д. Проект
используется автором (RollingHog) для ведения нескольких игровых кампаний,
каждая кампания — свой вариант приложения со своими данными и правилами.
Выкладывается на GitHub Pages: https://rollinghog.github.io/wr-pokon/

По словам README, при создании «нещадно эксплуатировалась LLM Qwen3-Coder».

## Точка входа

`index.html` — простой список ссылок на все приложения:

- `ChillyMorning.html` — базовый вариант («Холодное утро»)
- `custom/BnB.html`, `custom/pokras-spc.html`, `custom/Stach.html`,
  `custom/Stars.html`, `custom/Underdark.html` — варианты под конкретные кампании
- `utils/SquareGrid.html` — утилита (квадратная сетка)
- `vor-saga/index.html` — отдельный мини-проект (см. ниже)

## Архитектура базового приложения

Каждая HTML-страница подключает один и тот же набор скриптов:

1. `src/keywords.js` — словарь ключевых слов (объект `KW`)
2. `src/rules.js` — правила конкретной кампании: словари
   (`DICT_COMMON`), цены/категории объектов (`CATEGORY_PRICES`,
   `OBJ_CATEGORIES`), списки эффектов (`EFFECT_LISTS`), `TECH_EFFECTS`,
   настройки (`SETTINGS`: путь к карте, макс. HP юнита и т.п.)
3. `data/userParams.js` — пользовательские параметры (`DICT_USER`)
4. `data/data.json.js` — данные состояния (сохранение карты/объектов как JS-файл)
5. `index.js` (~125 КБ) — общий движок: canvas-рендеринг карты
   (`map-canvas` + `fog-canvas` для тумана войны), масштабирование,
   размещение фигур/текста, панель редактирования, счётчик хода,
   сохранение PNG и объектов в `.json.js`, загрузка объектов обратно.

Карта — PNG (исходник в Hexographer, высота гекса 96 px, файлы в `map/`).
Данные хранятся как `.json.js` файлы (обёртка JSON в JS, чтобы открывать
локально без сервера — через `<script src=...>`).

## Кастомные кампании (`custom/`)

Для каждой кампании: `<Имя>.html` (почти копия ChillyMorning.html со
своими заголовками/кнопками игроков) + папка `<имя>/` со своим набором:

- `data.json.js` — состояние карты
- `rules.js` — правила кампании
- `userParams.js` — параметры
- `tech/` — техдеревья и прочие md-доки
- `copy*.bat` — скрипты копирования данных

Кампании (по содержимому md-файлов):

- **pokras-spc** («Покрас в космосе») — космическая кампания
- **stars** — «космический магопанк с налётом ужасов», мультиплеер до 6
  человек, РПГ с ходами по квадратикам (интро в `custom/stars/intro.md`)
- **BnB** — фэнтези-кампания с техдеревьями (некромантия и т.п., `bnb/tech.md`)
- **Stach**, **Underdark** — аналогичные варианты

## Прочие части

- `src/calc.html`, `src/countRaceEffects.html` — калькуляторы (ресурсов и характеристик расы)
- `src/old_rules.js` — старые правила, оставлены для истории
- `vor-saga/` — отдельный самостоятельный инструмент (свой README, CSS,
  `ship_calculator.js`, `draw.js`, страницы budget/draw/fleet) —
  судя по всему, калькулятор/редактор кораблей для другой игры
- `xlam/` — md-заметки по сеттингу (школы магии `drop.md`, юниты `units.md`,
  техдеревья `tech.md`, расы и т.д.)
- `images/` — иконки/эмодзи для карты (кэшируются, см. коммиты)

## Конвенции и прочее

- Всё на русском (UI и доки), без пакетного менеджера и сборки — просто
  статические файлы.
- Git: ветка `master`, деплой на GitHub Pages (`.nojekyll` присутствует).
- README содержит планы по улучшению (undo через Ctrl+Z, строящиеся здания,
  таймеры completion/destruction, учёт списка юнитов, «метро» и др.).
- `post.txt` — вероятно, шаблон поста для игрового треда.
